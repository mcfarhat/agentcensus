Method

AgentCensus enumerates the ERC-8004 Identity Registry (0x8004A169…a432) by sequential ID, decodes each tokenURI (85% store metadata on-chain), indexes every ERC-8183 job in the AgenticCommerce kernel (0xea4daa31…eba6), and probes each declared endpoint's /erc8183/health with an SSRF-hardened prober. Classification is a published, deterministic ruleset. Every number on this page can be reproduced from public BSC data with the open-source indexer — no API keys, no trust required.
